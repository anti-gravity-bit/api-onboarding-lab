# API Onboarding Lab

Local Go demo of a small order API and a signed webhook receiver. It is a personal portfolio project for showing API onboarding and integration tests. Orders and webhook event ids live in memory and are gone when the process exits.

The quickstart command will be added after it has been run from this tree. There is no public docs site and no CI badge yet.
